FAQ

Robots constraints are explicit.

Does it crawl my site?

No. This MVP only analyzes pasted HTML head snippets, X-Robots-Tag rows, and robots.txt notes.

Does it use Search Console?

No. There is no Search Console, URL Inspection, OAuth, or external API dependency.

Does it guarantee indexing?

No. Robots directives can affect crawling, indexing, and snippets, but this is launch QA guidance and does not guarantee outcomes.

Can I paste private client snippets?

The app is browser-local, but you should still paste only public-safe or anonymized snippets.
