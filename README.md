# Meta Robots Conflict QA Briefs

Static MVP for checking pasted HTML head snippets, X-Robots-Tag rows, robots.txt notes, and launch intent before migrations or launch pages go live.

## Offer

Paste URL/head rows, optional X-Robots-Tag rows, robots.txt notes, launch context, and launch intent. Generate a copyable QA brief covering:

- noindex on intended indexable URL warnings
- nofollow, nosnippet, noarchive, and max-snippet warnings
- googlebot, bingbot, and generic robots directive conflicts
- X-Robots-Tag vs meta robots disagreement
- robots.txt crawler-access reminders

## Conversion Path

Billing is not connected. The MVP uses early-access, demo-request, and purchase-intent capture with a public-safe GitHub issue handoff.
